Interfaces
==========

This section is the API reference for the surfaces pretalx exposes to
plugins and other integrations: the signals and hooks plugins can react
to. Anything not listed here should be considered private and may change
without notice, whereas changes to the interfaces listed here will be
mentioned in the :ref:`changelog`.

For a browsable, linked overview of the core of the pretalx codebase
(models and domain logic), see the :doc:`/developer/interfaces/reference`.
